# Module 1: Solidity Basics

## Owner

Abdallah Abdurazak

## Overview

This module introduces the first Solidity concepts used throughout the course.
It focuses on primitive data types and simple function behavior.

## Sections

### Data Type

The `Data Type` section covers:

- Booleans
- Enums
- Signed integers
- String literals
- Unsigned integers

### Solidity Functions

The `Solidity Functions` section covers:

- Function arguments
- Console logging
- Function overloading
- Increment logic
- Pure functions
- View functions and addition

## Learning Goal

The purpose of this module is to build confidence with the syntax and runtime
behavior of Solidity before moving into more advanced contract patterns.
