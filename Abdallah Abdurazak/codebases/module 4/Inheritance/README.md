# Module 4 - Inheritance

## Overview

This section focuses on contract inheritance, override rules, and reusing base
contract behavior.

## Exercises

- 1 Inherit
- 2 Constructor Args
- 3 Virtual Override
- 4 Super
- 5 Ownable
- 6 Multiple Inheritance

## Goal

The exercises show how derived contracts inherit state and behavior from base
contracts while still customizing logic.
