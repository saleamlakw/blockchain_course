# Module 2 - Calling Contracts

## Overview

This section shows how one contract can call another contract, with and without
signatures.

## Exercises

- 1 Call Function
- 2 Signature
- 3 With Signature
- 4 Arbitrary Alert
- 5 Fallback

## Goal

The exercises demonstrate how to interact with external contracts and how call
paths change when function signatures or fallback behavior are involved.
