## What Is Inside

### Codebases

The `codebases` folder contains the Solidity exercises and tests for the full
course. The work is organized by module, with each module focusing on a
different concept.

### Materials

The `materials` folder is reserved for supporting course files and references.

### Screenshots

The `screenshots` folder stores proof images and visual evidence of completed
exercises.
