# Module 3 - Arrays

## Overview

This section focuses on fixed and dynamic arrays and how they behave in
storage and memory.

## Exercises

- 1 Fixed Sum
- 2 Dynamic Sum
- 3 Filter to Storage
- 4 Filter to Memory
- 5 Stack Club 1
- 6 Stack Club 2

## Goal

The exercises teach how to create arrays, transform them, and reason about how
array data moves through Solidity functions.
