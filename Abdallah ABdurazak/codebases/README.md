# Codebases Overview

## Purpose

This folder contains all Solidity learning exercises, grouped by module and
topic.

## Structure

- module 1: data types and Solidity functions
- module 2: address interactions and contract practice
- module 3: arrays, mappings, and structs
- module 4: inheritance and voting

## How to Read It

Each module folder contains the individual exercise folders and their test
files. The module-level README files explain the learning goal for that part of
the course.
