# Module 4: Inheritance and Voting

## Owner

Abdallah Abdurazak

## Overview

This module covers inheritance patterns and a full voting system built on top
of previous Solidity concepts.

## Sections

### Inheritance

The inheritance section covers:

- Inherit
- Constructor Args
- Virtual Override
- Super
- Ownable
- Multiple Inheritance

### Voting

The voting section covers:

- Proposal
- Cast a Vote
- Multiple Votes
- Voting Events
- Members
- Execute

## Learning Goal

The goal of this module is to combine contract reuse, constructor chaining,
override logic, and stateful voting workflows.
