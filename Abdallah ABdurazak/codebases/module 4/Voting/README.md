# Module 4 - Voting

## Overview

This section focuses on building a complete voting workflow with proposals,
members, votes, events, and execution.

## Exercises

- 1 Proposal
- 2 Cast a Vote
- 3 Multiple Votes
- 4 Voting Events
- 5 Members
- 6 Execute

## Goal

The exercises teach how to structure a real voting contract with controlled
participation and state transitions.
